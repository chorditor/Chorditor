# 푸시 CTR 분석 기록

## 데이터 정의

- **Before**: quiz 넛지 단일종. sent 323, click 18, CTR 5.57%. 더 이상 안 늘어남(과거 데이터, B/A 관점 이걸로는 추가 분석 불가).
- **After**: 넛지+피크소진 등 15종 혼합. 계속 쌓이는 중, 스냅샷 시점마다 숫자 조금씩 달라짐(예: 2026-08-10 기준 sent 7571 / click 980).

## 1. 전체 CTR B/A (Two-proportion z-test)

- pooled p = 998/7894 = 12.64%
- z = 3.90, p < 0.001 → **유의함**
- 주의: after 전체의 89%가 피크소진 알람이라 사실상 "피크소진 vs before quiz" 비교에 가까움. 순수 "전체 개선" 해석엔 왜곡 있음.

## 2. 피크소진 제외 후 B/A

- after(피크 제외): sent 814, click 76, CTR 9.34%
- z = 2.08, p ≈ 0.038 → 유의하지만 0.05 기준 경계선(0.01 기준 탈락)
- before가 quiz 단일종이라 after(여러 종 혼합)와 population 정의 자체가 다름 — 엄밀히 apples-to-apples 아님.

## 3. 카테고리 간 비교 (After 내부, 피크 포함)

분류(5개, 외부 분석 참고해 재구성 — 원 분류에서 누락됐던 5종은 성격 맞춰 배정):

| 카테고리 | 구성 | sent | click | CTR |
|---|---|---|---|---|
| A. 보상/게임화(피크) | 피크가 가득 찼어요! | 6757 | 904 | 13.38% |
| B. 실습/훈련형 | 스케일훈련, 주법리듬훈련, 코드진행리스트, 코드조합훈련 | 171 | 19 | 11.11% |
| C. 부담경감형 | 짧게라도괜찮아요, 잠깐5분만어때요, 기타잡아볼까요, 오늘도한걸음 | 411 | 43 | 10.46% |
| D. 퀴즈형 | 코드맞추기 | 166 | 12 | 7.23% |
| E. 감성/복귀형 | 잠깐기타어때요, 다시함께해요, 오랜만이에요, 기다리고있었어요 | 63 | 2 | 3.17% |
| (제외) | 이번주결산 | 3 | 0 | — n=3, 통계열외 |

전체 동질성 검정: χ² = 14.03, df=4 → p ≈ 0.007 (유의함)

쌍별 z-test:

| 비교 | z | p | 판정 |
|---|---|---|---|
| A vs D | 2.31 | 0.021 | 유의 |
| A vs E | 2.37 | 0.018 | 유의 |
| A vs C | 1.70 | 0.090 | 경계, 미유의 |
| A vs B | 0.86 | 0.389 | 미유의 |
| B vs E | 1.88 | 0.060 | 경계, 미유의 |
| C vs E | 1.84 | 0.066 | 경계, 미유의 |
| B vs D | 1.23 | 0.218 | 미유의 |
| C vs D | 1.20 | 0.231 | 미유의 |
| D vs E | 1.14 | 0.253 | 미유의 |
| B vs C | 0.23 | 0.817 | 미유의 |

**결론**: 전체 χ² 유의성은 A(피크)가 혼자 견인. A를 뺀 B/C/D/E끼리는 전부 미유의 — "어느 넛지 카테고리가 더 낫다"고 순위 매길 근거 아직 없음. "차이 없다"가 아니라 "차이 유무를 판단할 통계적 근거가 부족"한 상태(E는 click=2건뿐이라 검정력 자체가 낮음).

## 4. 데이터 스냅샷 차이 관련

같은 로직으로 다른 곳에서 돌린 분석과 비교 시 after N이 7470 vs 7571로 차이났는데, 전부 피크소진 항목 하나에서만 발생(쿼리 실행 시점 차이, 계속 쌓이는 데이터라 자연스러운 현상). 나머지 14종은 완전히 일치했음. 모니터링 목적으로 반복 조회하는 것 자체는 무해 — 사전에 정한 컷오프(모수/기간) 전에 결과 보고 실험을 중단/변경하지만 않으면 됨.

## 다음 계획

- Before quiz는 데이터 고정이라 더 이상 B/A 비교 불가 — 이 관점은 종료.
- **After 데이터를 계속 쌓아서** 카테고리 간(B/C/D/E) 유의차 재검정 예정.
- **연령대별, 성별 차이** 분석 예정 — 쿼리/설계는 다음 세션에서 진행.
