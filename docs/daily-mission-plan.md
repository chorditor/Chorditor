# 데일리 미션 컨셉 (1.3.4.2)

기타 학습 도구가 아니라 "기타 레슨 선생님"의 핵심가치를 보여주는 시스템.
매일 접속 시 오늘 할 일을 바로 제공받고 따라가는 구조로, 훈련 편식을 막고 유저 실력 성장에 관여한다.

## 1. 진입 (게이트)

- 홈 화면 진입 **전** 강제 노출. 단, 패스 버튼으로 언제든 바로 홈 진입 가능(패스 마찰 최소화).
- 진입점 UI: "오늘의 미션 시작" 버튼 1개 (3개 카드 나열+순서선택 방식은 폐기 — 1사이클 구조로 통합하면서 불필요해짐).

### 게이트 재노출 규칙
- 3문제 전부 완료 **또는** 패스를 누른 경우 → 그날 하루 게이트 소멸(다음날까지 재노출 없음)
- 그 외(미완료 + 패스도 안 한 상태) → 앱 재실행(세션)마다 재노출

### 진행 상태 저장
- 로컬(localStorage)에 진행 위치(세그먼트+문제 인덱스) 저장
- 자정 리셋 전까지는 정확한 위치로 이어서 재개 가능 (도중 이탈 시에도 처음부터 다시 X)

## 2. 대상 컨텐츠

퀴즈형 3종만 사용: **코드맞추기 / 스케일훈련 / 코드조합훈련**.
주법리듬훈련·코드진행리스트는 "완료" 판정 트리거가 없어 제외.

페르소나별 난이도 후보군은 기존 `supabase/push_nudge_persona.sql`(unboxing/beginner/sheet_reader/home_master + guitar_master는 추가 필요)의 training별 levels/priority를 참고해 추후 별도 확정.

## 3. 본편 플레이 구조 — 1사이클 15문제

**고정 순서, 혼합 없음**: 코드맞추기 5문제 → 스케일훈련 5문제 → 코드조합훈련 5문제. 하나로 이어진 사이클.

- **코드맞추기**: 기존 2모드("코드보고 이름맞추기" / "이름보고 코드맞추기")를 문제마다 랜덤으로 섞어서 출제.
- **스케일훈련 / 코드조합훈련**: 기존 훈련 로직 그대로, 5문제/단위만 뽑아 출제.
- **타이머 없음** — 코드맞추기 원래 있던 시간제한 시스템도 데일리미션 안에서는 제거.
- **픽 소모 없음** — 평소 컨텐츠 진입 시 소모되는 픽(코드맞추기 2~5, 스케일훈련 2 등, [[peak_currency_system_v130]])을 데일리미션 경로에서는 우회. 보상으로 픽을 주는데 입장에 픽을 쓰면 순환구조가 되어 무의미해짐.

## 4. 결과 화면

15문제 종합 채점 후 한 화면(세로 스크롤)에 표시. 종합 평균 점수 등 복합 계산은 하지 않음(패스).

### 상단 — 총 평가 (테스트결과 스타일 피드백)
정답률 패턴에 따라 3갈래 텍스트 피드백만 노출 (실제 페르소나 변경 액션 없음, 페르소나 승급/강등 시스템은 완전히 별도 논의로 미룸):
1. 전반적 고정확도 → "잘하고 있어요, 다음 단계 도전해보세요" 식 성장 피드백
2. 특정 컨텐츠만 낮음, 나머지 양호 → 그 컨텐츠 집중연습 유도
3. 전반적 저정확도 → 쉬운 난이도 조정 유도

### 하단 — 컨텐츠별 결과 (플레이 순서대로: 퀴즈 → 스케일 → 조합)
각 섹션: 가로로 넓은 정규분포 그래프 + "상위 n%" 표시.

- **통계는 실시간 집계 아님.** 현재까지 데이터를 참고해 임의로 잡은 **고정 정규분포 프리셋**(평균/표준편차 상수)을 기준으로 유저의 정답수(스케일은 정답 퍼센트)로 z-score만 계산해 상위%를 산출. 실유저 데이터로 실시간 갱신되지 않음.
- 프리셋을 페르소나별/난이도별로 분리할지는 추후 결정.

## 5. 오답노트

- 1회차 15문제 채점 후, 오답만 골라 원래 순서 그대로 재출제 (정답이었던 문제는 노출 안 함).
- 타이머 없음, 통계 측정 없음.
- **언제든 패스 가능** — 오답을 다 못 맞춰도 미션 완료로 인정(꼼수 방지 안 함, 완주 유도는 보상 차등으로만).
- 스케일훈련: 정답 노트는 화면에 계속 표시 유지, 오답 노트만 반복 출제.

## 6. 보상

클리어 시 **1회만** 지급 (개별 문제/세그먼트별 보상 없음).

| 상황 | 보상 |
|---|---|
| 1회차 퍼펙트(오답 없음) | 픽상자 2개 |
| 오답 있었으나 오답노트 패스 | 픽상자 1개 |
| 오답 있었으나 오답노트 끝까지 완주 | 픽상자 2개 |

## 7. 진입 UI 재배치

기존 홈 하단바 `#hdb-quest`("퀘스트 보상") 라벨을 **"미션"**으로 변경 — 성격을 데일리미션+기존 누적퀘스트를 아우르는 것으로 확장.

- 모달 최상단에 **완전히 분리된 "오늘의 미션" 섹션** 신설 (기존 `_questCardHtml` 카드 스타일과 다르게, 매일 리셋된다는 걸 시각적으로 구분).
- 기존 누적형 퀘스트 목록(`renderQuestList`)은 그 아래 그대로 유지.
- 홈 상단 `#topbar-level`(레벨 칸) 대체안은 검토 후 기각 — 자리 유지, 퀘스트모달 재활용으로 결정.

## 8. 출석제도와의 관계

완전 별개 레이어.

- 출석 보상은 홈 진입 시 그대로 지급.
- 기존 "출석 랜덤 픽상자"는 데일리미션 완료보상(픽상자)과 중복되므로 **폐지**.
- 폐지되는 랜덤 픽상자는 추후 다른 자리에 재배치 예정 (미정, 별도 논의).

## 미정 / 후속 논의 필요

- 페르소나별/난이도별 미션 문제 풀 상세 (난이도 디테일은 사용자가 직접 정할 예정)
- 정규분포 프리셋 수치, 페르소나별 분리 여부
- 페르소나 승급/강등 시스템 (완전 별도 논의)
- 폐지된 출석 랜덤 픽상자의 재배치처
- UI 문구/비주얼 톤 디테일
- 실제 구현 설계 (파일 구조, DB 스키마, 로컬 상태 저장 포맷)
