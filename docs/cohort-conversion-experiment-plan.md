# 신규 코호트 구독 전환 검증 실험 계획

> 작성일: 2026-10-11 · 상태: 계획 확정, 관찰 진행 중
> 목적: 인스타그램 유입으로 새로 들어온 10~40대 코호트에서 **구독 전환이 실제로 발생하는지** 검증한다.
> 목표 전환율 도달이 아니라 "전환이 일어나는가"를 확인하는 실험이다.

## 1. 배경

### 1-1. 이전 가설과 결과

- 유튜브 유입 코호트(50~60대 중심)에 대해 구독 전환율이 못해도 1%는 나올 것으로 예상했다.
- 실제로는 구독자 8명이 전원 유튜브 영상 업로드 직후 며칠 안에 발생했고, 이후 수개월간 신규 전환이 단 1건도 없었다.
- 가설은 실패로 보고 코호트 선정이 잘못되었음을 인정한다.

### 1-2. 실패 원인 추정 (검증되지 않음)

1. 유튜브 영상이 무료 앱으로 소개되었고, 이후 피크 시스템 등 유료 구조가 자리잡아 페이월 저항이 컸을 가능성.
2. 50대 이상은 구독형 결제 시스템에 익숙하지 않은 세대일 가능성.
   - 연령별 구독 전환율 자료는 확보하지 못했다. 경험적 추정으로 취급한다.

### 1-3. 새 방향

- 실패를 새로운 문제제기로 삼아 20~30대 신규 코호트를 유입시킨다.
- 근거(경험적, 정확한 자료 아님): 구독형 서비스에 익숙한 세대이며, 코로나 시기 이후 취미로 악기를 배우는 20대 비중이 늘었다는 전언.
- 수단: 기타 학습 팁 영상에 앱 언급, 프로필 링크 안내 (광고 집행 아님, 오가닉).

## 2. 선행 분석 결과 (코호트가 달라졌는가)

### 2-1. 연령 분포 비교

| 연령대 | 10/1~10/8 가입 (n=370) | 10/9 이후 가입 (n=87) |
|---|---|---|
| 10대 | 10 (2.7%) | 19 (21.8%) |
| 20대 | 4 (1.1%) | 38 (43.7%) |
| 30대 | 30 (8.1%) | 13 (14.9%) |
| 40대 | 39 (10.5%) | 3 (3.4%) |
| 50대 | 116 (31.4%) | 4 (4.6%) |
| 60대 | 118 (31.9%) | 7 (8.0%) |
| 70대 | 27 (7.3%) | 0 (0.0%) |
| 80대 | 2 (0.5%) | 1 (1.1%) |
| 미상 | 24 (6.5%) | 2 (2.3%) |

### 2-2. 통계 검정

| 검정 | 결과 |
|---|---|
| 카이제곱 동질성 (9구간) | χ² = 229.8, df = 8, p = 3.2e-45 |
| 몬테카를로 순열 검정 | p < 0.0002 |
| 구간 병합 후 카이제곱 | p = 5.4e-46 |
| 평균 연령 (구간 중앙값 근사, 미상 제외) | 약 55.8세 → 30.4세, Welch t p = 2.5e-26 |
| 효과 크기 | Cramér's V = 0.71 |
| 50대 이상 비중 | 71.1% → 13.8% |
| 30세 미만 비중 | 3.8% → 65.5% |

### 2-3. 결론

- 10월 9일 이후 가입자는 이전과 **연령 구성이 통계적으로 완전히 다른 코호트**다.
- 유입 경로가 직접 기록되지 않았으므로, 인스타그램 유입이 원인이라는 해석은 "다른 마케팅 활동이 없었다"는 소거법 추정이다.
- 이전 코호트는 유튜브 유입이 대다수, 이후 코호트는 인스타그램 유입(직접 시청 + 지인 추천)이 대다수일 것으로 본다.

## 3. 실험 설계

### 3-1. 가설

> 10월 9일 이후 유입된 10~40대 코호트에서는 가입 후 35일 이내에 구독 전환이 기준선을 넘어 발생한다.

### 3-2. 코호트 정의

| 코호트 | 정의 | 역할 |
|---|---|---|
| 새 코호트 | 가입일 ≥ 2026-10-09 (KST) + 10대~40대 | 검증 대상 |
| 기존 코호트 | 가입일 < 2026-10-09 + 50대 이상 | 비교군 |

- 연령은 `subscriptions.birth_year` 기반 10살 단위(연 나이 근사).
- 날짜 조건을 함께 거는 이유: 연령만으로 나누면 유튜브 시기에 가입한 40대 이하가 새 코호트에 섞인다.
- 가입일 기준: `subscriptions.created_at`. 앱은 로그인해야 사용 가능하므로 설치 수 ≈ 가입자 수로 본다.
- 테스트 계정(관리자 uid)은 제외한다.

### 3-3. 관찰과 판정

| 항목 | 내용 |
|---|---|
| 관찰 창 | 가입 후 35일 이내 (업계 지표 download-to-paid D35와 같은 기준) |
| 전환 정의 | 결제 완료 (경로 무관). 체험 이벤트 경유 여부는 경로별로 따로 표시 |
| 기준선 | 8 / 13,000 ≈ 0.062% (기존 전체 가입자 대비 구독자) |
| 표본 | 새 코호트 가입자 300명 도달 시점에 1회 판정 |
| 지지 기준 | 35일 내 전환 **2건 이상** |

### 3-4. 기준선 대비 유의성 (n = 300, 기대 전환 ≈ 0.18건)

| 전환 건수 | p-value (기준선 이상일 확률, 포아송) |
|---|---|
| 1건 | 0.17 (유의하지 않음) |
| 2건 | 0.015 |
| 3건 | 0.0009 |

### 3-5. 판정 규칙

- **2건 이상:** 가설 지지(예비). 전환 유저의 연령대를 확인해 가설 대상층(20~30대)에서 발생했는지 같이 기록한다.
- **2건 미만:** 기각이 아니라 관찰 미완료. 300명 도달 시점에는 늦게 가입한 유저의 35일 창이 끝나지 않았으므로, 마지막 가입자의 35일 경과 후 한 번 더 판정한다.
- **충분한 표본에서 0건:** 가설 기각. (전환율 95% 상한 3/n 기준: 300명이면 약 1%, 600명이면 약 0.5%)
- 중간 확인은 진행 상황 파악용으로만 하고, 2건이 나왔다고 멈추지 않는다 (판정은 300명 도달 시점으로 고정).

### 3-6. 보조 확인 (승인 후 쿼리 작성)

1. 새 코호트 누적 가입자 수 (300명 도달 여부)와 35일 내 전환 건수.
2. 기준선 8건의 연령대. 8건이 전부 50대 이상이면 기존 기준선은 사실상 50대 이상의 기준선이므로 연령별 기준선으로 보정한다.
3. 전환 건의 경로(체험 이벤트 경유 / 일반 결제)와 유저 연령대.

## 4. 한계점

- **유입 경로를 직접 기록하지 않았다.** 채널 구분은 소거법 추정이다. 코호트는 날짜·연령 기준으로만 분리되며 완전히 분리되지 않는다 (10/9 이후 가입자의 12.6%가 50대 이상, 이전 가입자의 3.8%가 30세 미만).
- 연령은 `birth_year` 기반 연 나이 근사로, 만 나이와 최대 1살 차이가 날 수 있다.
- 10대가 신규 코호트의 21.8%를 차지한다. 가설 대상이 아니며 결제 능력·보호자 동의 제약이 있다. 전환 건이 10대라면 가설 지지 근거로 보기 어렵다.
- **7일 Pro 체험 이벤트(2026-10-31 23:59:59 KST까지 클레임 가능)가 같은 시기에 열려 있다.** 신규 코호트 전환에 체험 효과가 섞일 수 있다.
- 기존 코호트의 구독자 8명이 전부 유튜브 영상 직후 며칠에 몰려 있어, 기존 코호트의 장기 전환율은 사실상 0에 가깝다. 비교군의 성격이 "일반 오가닉"과 다를 수 있다.
- 20~30대 구독 친화 및 코로나 세대 악기 수요는 정확한 자료가 아닌 경험적 가설이다.
- 업계 벤치마크(RevenueCat) 표본은 수익화에 적극적인 앱들이라 1인 니치 앱과 다르다. 목표 비교용이 아니라 참고용으로만 쓴다.

- **적용 완료:** 인스타그램 프로필 링크를 UTM이 붙은 Bitly 링크로 교체.
  - 대상 URL: `https://play.google.com/store/apps/details?id=com.chorditor.app&referrer=utm_source%3Dinstagram%26utm_medium%3Dorganic_video%26utm_campaign%3Dprofile_link`
  - Play 콘솔 획득 보고서의 "제3자 추천"에서 집계 확인 (유저 단위 연결은 안 됨, 링크 클릭 유입만 잡힘).
- **보류:** 유튜브용 UTM 링크 (`utm_source%3Dyoutube`, 필요 시 같은 형식).
