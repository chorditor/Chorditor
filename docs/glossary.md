# Chorditor 번역 용어집 (한 / 영 / 일 / 스)

> 번역 작업의 SSOT. 새 문구를 번역하기 전에 여기서 용어부터 찾을 것.
> 순서: 영어(확정) → 일본어(초안 v0) → 스페인어(초안 v0). 일본어·스페인어는 출시 전 원어민 검수 필요.
> 목표: 직역이 아니라 현지 문화에 녹아든 자연스러운 번역. 밴드·음악 밈은 과하지 않게, 가끔만.
> 방침: 번역은 공수가 크므로 약간의 어색함은 감수. 일관성 우선, 어색한 부분은 출시 후 피드백으로 보정.

| 언박싱 1일차 | Day 1 Newbie | Still has the tag on | 開封1日目 | 買ったばかり!タグも付いたまま | Estrenando Guitarra | Con la etiqueta todavía puesta |
| 굳은살 비기너 | Callus Builder | Practicing here and there | 指先修行中 | ぼちぼち練習中 | Callos en Construcción | Practicando poco a poco |
| 악보 의존자 | Tab Player | Lost without the tabs | TAB譜プレイヤー | タブ譜がないと不安 | Amante de las Tabs | Sin tabs me pierdo |
| 방구석 기타마스터 | Bedroom Shredder | Great when nobody's watching | 内弁慶ギタリスト | ひとりなら弾けるんです | Guitarrista de Cuarto | Me luzco cuando nadie mira |
| 기타마스터 | Guitar Master | | ギターマスター | | Guitar Master | |

- 영어 "Bedroom Shredder"가 속주 이미지로 과하면 Bedroom Guitarist로 내릴 수 있음.
- 「内弁慶」은 "집에서만 큰소리치는 사람" 관용구. 영어 부제의 유머를 일본 감성으로 재창작한 것.
- 스페인어는 성별 중립으로 풀었음(estrenar=새 물건 첫 사용, amante·guitarrista는 epicene, 부제는 1인칭 동사). Guitar Master는 Maestro/Maestra 성별 문제 때문에 영어 그대로.
- 스페인어 "cuarto"는 중남미 기준, 스페인은 habitación.

- 에디터 탭 영어 라벨: Root / Triad / 7th / Func. / Ext. / Slash.

- 스페인어 Cejilla: 스페인에서는 capo도 cejilla라고 불러 혼동 가능, 중남미 기준이면 문제없음. Fret=Traste, Capo=Capo.

## 5. 톤 가이드

- 공통: 친근한 동행 선생님 톤. 경쟁·질책 문구 금지 (한국어 원칙과 동일).
- 영어: 축약형(you're, let's)을 쓰는 친근한 현재형. 격식체 회피. 공통 버튼: Maybe later / Skip / Got it / Next.
- 일본어: です・ます체, 부드러운 어미(〜しましょう, 〜できますよ). 명령형 회피. 軽音部·スタジオ入り 같은 소재는 가끔만.
- 스페인어: 중남미 중립(es-419) + tú. voseo·vosotros·지역 속어 금지. 성별 중립 표현(o/a 분리 안 함). 문화 소재(ensayo 등)는 가끔만. UI 길이가 영어보다 20~30% 길어서 좁은 라벨은 약어 후보를 따로 준비.
- 영어 푸시/넛지는 번역이 아니라 톤 재설계. 별도 템플릿 테이블로 관리 (`push_templates_en`).

## 6. 미결정·메모

- 일본어·스페인어 초안은 출시 전 원어민 검수 필요.
- 음이름 표기: 영어·일본어는 C·D·E(코드 이름과 통일). 스페인어(Do Re Mi vs C·D·E)는 그 언어 작업 때 결정.
- 일본어 용어 확정(2026-10-08): 練習ルーム / ギターロードマップ / コード進行 / 음이름 C·D·E / 페르소나는 표의 초안 그대로.
- 부제 문구(Reharm Quiz 등)는 번역 작업 때 다듬기.
- 약관/개인정보처리방침은 법률 검수급 별도 작업.
